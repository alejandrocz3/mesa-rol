# mesa-rol
Mesa de rol, permite añadir un mapa y fichas para la partida.

# launch
1. Descomprime el zip y, dentro de mesa-rol, ejecuta npm install y luego npm start.
2. Abre http://localhost:3000. Los demás entran con la IP de la VPN, por ejemplo http://IP-DE-LA-VPN:3000, o con el enlace de la nube.


# Qué incluye:
- Mapa: cualquiera puede subir una imagen, que se convierte en el fondo para todos. Se reduce en el navegador a un máximo de 2400 px antes de enviarla.
- Fichas: nombre, color de borde, imagen opcional y tamaño. Cualquiera puede arrastrarlas y todos lo ven en directo. Con doble clic se borran.
- Posición: las fichas se guardan en porcentajes sobre el mapa, así que quedan en el mismo sitio en pantallas de cualquier tamaño.
- Nuevos jugadores: al entrar a mitad de partida ven el mapa y las fichas tal como están.
